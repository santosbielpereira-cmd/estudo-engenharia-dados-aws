# Estudo de Engenharia de Dados na AWS

Material gratuito, em português, para quem estuda engenharia de dados com perfil de software e plataforma.

O objetivo é explicar o **porquê** de cada conceito, e não só o "como": cada tema vem com diagrama, código de exemplo, armadilhas comuns e perguntas de entrevista.

## Conteúdo

| Página | O que tem |
|---|---|
| [`roteiro.html`](roteiro.html) | Trilha de 8 semanas: Python, APIs e microsserviços, Lambda, ECS, IAM, eventos (SNS, SQS, EventBridge), bancos, S3, Glue, EMR, Athena, CI/CD com Terraform e observabilidade. Checklist com progresso salvo no navegador. |
| [`fichas-e-simulado.html`](fichas-e-simulado.html) | Fichas técnicas no formato situação → o que é → por que funciona → como usar → cuidado → entrevista. Spark (driver, executors, shuffle, broadcast join, skew, AQE, DataFrame, groupBy, window, repartition e coalesce), formatos (Parquet, arquivos pequenos, Iceberg) e problemas reais da AWS. Inclui dicas de entrevista, **simulado com 30 questões** e casos abertos de arquitetura. |

## Como usar

1. Abra o `index.html` (ou o site publicado no GitHub Pages).
2. Comece pelo roteiro para ter o panorama.
3. Nas fichas, leia a situação e tente responder antes de abrir a explicação.
4. Faça o simulado sem consultar e revise os temas em que errou.

As páginas são HTML estático, sem build e sem dependências além de fontes do Google Fonts.
